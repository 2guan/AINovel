# 公开小说阅读页边界

## Background

多用户版本默认要求工作台内容按用户隔离，但小说正文也需要一个面向读者的分享入口。这个入口服务的是“阅读已经生成的小说正文”，不是进入创作工作台，也不是绕过作者账号查看创作资产。

## Decision

公开阅读页采用“知道链接即可阅读”的边界：游客不需要登录，也不会出现在工作台权限体系中。后端为公开阅读提供独立只读接口，只返回阅读所需字段，包括小说标题、简介、作者显示名、已生成正文的章节和基础统计。

## Current Rule

- 公开阅读入口从小说列表卡片进入，打开独立页面，不复用需要登录的预览页。
- 公开阅读接口必须挂载在认证中间件之前，并保持只读。
- 公开阅读接口只返回正文阅读需要的数据，不返回任务、模型配置、提示词、知识库、资产内部状态、导演推进状态或其他创作管理字段。
- 章节列表只展示有正文内容的章节；空规划章节不作为读者可读内容。
- 阅读页以章节正文为主，不展示全书梗概；手机端可以提供分页阅读和滚动阅读切换，分页只影响前端阅读体验，不改变章节数据边界。
- 手机分页阅读应固定在当前屏幕内完成排版，不出现正文纵向滚动条。分页交互遵循常见阅读器习惯：左侧区域回到上一页，右侧区域进入下一页，中间区域显示或隐藏阅读控制；滑动翻页可以作为补充手势。
- 手机分页的页面宽度和位移应保留浏览器实际小数像素宽度，不能用整数取整计算；否则连续翻到后续页时会累积偏移，导致页面边缘文字被裁切或露到相邻页缝隙。
- 书名页和章节信息页属于阅读内容流，不属于浮层控制。全书开头的书名页应单独占一页；每章正文前的章节信息页也应单独占一页。
- 手机分页的章节选择、分页 / 滚动切换、字号和主题控制必须以浮层形式出现，不能占用正文布局高度；显示或隐藏控制项不应触发正文重新分页。
- 工作台仍然按登录用户隔离。公开阅读页的开放性只适用于已知小说链接的读者阅读，不改变作者、管理员和待审核用户在工作台内的权限。

## Failure Modes

- 如果公开阅读页复用登录态详情接口，游客会被拦截，且容易把创作管理字段暴露给阅读侧。
- 如果公开接口返回完整小说对象，后续新增字段时可能无意暴露创作资产或内部运行状态。
- 如果公开阅读加入小说索引或搜索，需要单独设计发布状态、下架、可见范围和作者授权规则，不能默认把所有小说列出。
